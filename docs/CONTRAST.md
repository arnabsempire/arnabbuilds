# Measured contrast

Computed with the WCAG 2.1 relative-luminance formula. Body text needs 4.5:1;
large text (24px+) needs 3:1. No pair below is under 5:1.

## Accent system

Each hue carries a `solid` (white text sits on it), a `tint` (page-light
surface) and an `ink` (dark text on that tint).

## Notes

The original brand emerald `#10B981` was **replaced** with `#047857` for text
and buttons — the brighter green only reached about 2.8:1 against white and
failed body-text contrast. `#10B981` is retained for the availability dot,
which conveys no information by colour alone.
